# HR Resume Matcher Portable

Отдельная Windows-программа для сопоставления Excel-реестра кандидатов с файлами резюме.

Программа работает локально:

- без AI;
- без браузера и локального сервера;
- без LibreOffice;
- без чтения содержимого PDF/DOC/DOCX;
- без отправки данных во внешние сервисы.

Основной источник сопоставления — ФИО из Excel и имя файла резюме. Поддерживаются русские, латинские и частые белорусские варианты написания: например, `Громов Сергей` ↔ `Siarhei Hromau`, `Петрова Ольга` ↔ `Olga Petrova`.

## Как пользоваться

1. Запустите `HRMatcher.exe`.
2. Нажмите `Загрузить Excel` и выберите Excel-реестр.
3. Нажмите `Загрузить резюме` и выберите папку с PDF/DOC/DOCX.
4. Нажмите `Выбрать папку` и укажите папку результата.
5. Нажмите `Сопоставить`.

После обработки в окне станут доступны кнопки:

- `Открыть Excel-отчет`;
- `Открыть готовые резюме`;
- `Открыть резюме на проверку`;
- `Открыть папку результата`.

В папке результата появятся:

- `matched_resumes/` — уверенно найденные резюме;
- `review_resumes/` — похожие, но требующие ручной проверки;
- `resume_match_report.xlsx` — Excel-отчет со всеми строками, статусами и причинами.

## Статусы

- `найдено` — программа уверенно нашла одно лучшее резюме.
- `на проверку` — совпадение похоже, но есть риск ошибки.
- `не найдено` — подходящего файла нет или score слишком низкий.

## Словарь вариантов имен

Файл `config/name_aliases.json` можно расширять вручную:

```json
{
  "громов": ["gromov", "hromau"],
  "сергей": ["sergey", "siarhei"]
}
```

После изменения словаря программу пересобирать не нужно, если файл лежит рядом с `.exe` в папке `config`.

## Проверочные данные

В публичный portable-архив не включаются реальные Excel/PDF-примеры с персональными данными. Для автоматической проверки в проекте используются синтетические тесты, а реальные файлы можно проверять локально на компьютере, где они уже лежат.

## Windows 11: важные нюансы

Перед передачей программы заказчику проверьте:

```text
WINDOWS_11_CHECKLIST_RU.md
```

Коротко: программа работает автономно без AI, но для 3000+ файлов лучше запускать ее из распакованной папки на локальном диске, с закрытым Excel-отчетом и доступной на запись папкой результата.

## Запуск из командной строки

```powershell
python -m hr_matcher.cli --registry "C:\data\registry.xlsx" --resumes "C:\data\resumes" --output "C:\data\result"
```

## Сборка под Windows 11

Требования для сборочной машины:

- Windows 11 x64;
- Python 3.11+.

Команда из папки `portable_matcher`:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build_windows.ps1
```

Результат:

```text
dist\HRMatcherPortable\HRMatcher.exe
dist\HRMatcherPortable\config\name_aliases.json
dist\HRMatcherPortable\README.md
```

Эту папку можно передать заказчику как portable-программу.
